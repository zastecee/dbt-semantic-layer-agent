- Execute MetricFlow queries
- List available metrics
- List available dimensions
- Return generated SQL using MetricFlow explain
- Return query results as Pandas DataFrames
- Convert results into structured JSON

The MCP server must expose the following tools.



health_check()

Purpose:
Check if MetricFlow and the Semantic Layer are operational.

Internally execute:

mf health-check

--------------------------------------------------

list_metrics()

Purpose:
Return all available metrics.

Internally execute:

mf list metrics

--------------------------------------------------

list_dimensions(metric_name)

Purpose:
List dimensions available for a metric.

Internally execute:

mf list dimensions --metrics <metric_name>

--------------------------------------------------

explain_metric(metric_name)

Purpose:
Return metadata for a metric.

The response should include:

- metric name
- description
- measure
- dimensions

--------------------------------------------------

query_metric(
    metric_name,
    dimensions=None,
    start_date=None,
    end_date=None,
    limit=100
)

Purpose:
Execute business queries using MetricFlow.

Internally use commands equivalent to:

mf query \
  --metrics total_revenue \
  --group-by country \
  --start-time 2026-01-01 \
  --end-time 2026-12-31

Never generate manual SQL.

Return structured JSON.

--------------------------------------------------

get_time_series(
    metric_name,
    granularity,
    start_date,
    end_date
)

Purpose:
Return metric evolution over time.

Internally use MetricFlow.

Example:

mf query \
  --metrics total_revenue \
  --group-by metric_time__month

--------------------------------------------------

top_n(
    metric_name,
    dimension,
    limit
)

Purpose:
Return ranking data.

Example:

Top 10 partners by revenue.

Must use MetricFlow.

--------------------------------------------------

metric_sql_preview(
    metric_name,
    dimensions
)

Purpose:
Return the SQL generated by MetricFlow.

Internally use:

mf query --explain

Return:

- generated SQL
- query plan
- metric information

The SQL must be generated by MetricFlow.

Do not manually build SQL.
